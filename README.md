A single satirical sentence roasting lawmakers who write hundreds of pages of law to govern artificial intelligence, then stall the vote because nobody in the room can turn the draft itself into a PDF. The program is deterministic and model-free: it writes that one fixed line to `entry.txt` on every run.

The line is 162 characters long, exactly one sentence, inside the competition's 1–320 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
